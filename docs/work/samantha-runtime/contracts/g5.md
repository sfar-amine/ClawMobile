# G5 — date du reçu de déploiement visible

`GET /v1/updates` ajoute `items[id=companion].deployedAt`, ISO UTC ou null.
La version npm et son suffixe de commit court, déjà fournis par
`companionBuildVersion` depuis #85, restent inchangés. Le commit complet est lu
une seule fois au démarrage par le mécanisme existant ; aucun lecteur Git ajouté.

`updatesControl.generate` compose le résultat du helper tier0 existant avec
`withCompanionDeploymentDate` et le propriétaire G4 unique
`latestCompanionDeploymentAt(target)`. Le lecteur, les bornes et le cache des
reçus restent ceux de G4 : `~/.openclaw/deploys`, confirmé en lecture seule sur le
S24, 15 reçus Companion et 7 app, dont 8 captures nettoyées publiées sous
`fixtures/s24-2026-10-10/g4/deploy-receipts.json`.

Seul un reçu Companion `state=deployed` correspondant au commit complet prouvé
apporte sa date `at`. Absence, indisponibilité, projection partielle, préfixe
ambigu ou date invalide donnent null. Ni heure courante, mtime, date de manifest
ni date Git ne sont substituées. Reçus app, refused ou rolled_back ne prouvent pas
la date de la version courante. La projection ne modifie ni les fichiers du
propriétaire ni les autres lignes d'updates.

Budget existant : `/updates`, 4 s dans `companion-acceptance.py` ; aucune nouvelle
route ni capability. Le test en CI utilise la projection HTTP réelle
`p0-3/updates.json` pour le binding, puis le vrai handler HTTP et le vrai helper
`tier0-native-read.py`, avec un délai supplémentaire de 550 ms, latence capturée.
Dix lectures froides concurrentes appellent un helper et un lecteur G4 ; les
lectures chaudes réutilisent leurs caches. La lecture positive des reçus réels
est testée sans changement. Pour l'intégration HTTP seulement, le target d'un
reçu réel est remplacé explicitement par HEAD local : cette variation ne constitue
pas une preuve de déploiement physique de la branche. Les fichiers restent identiques.

Tests : `test-update-deployment-date.cjs` (binding, null, calendrier, vrai owner,
HTTP et budget), `test-updates-read.cjs` (versions et propriétaire tier0),
`test-deployment-receipts.cjs` (G4, bornes 600 reçus, états, confidentialité).

# F6 — Reçus Remote Bridge bloqués : état terminal `abandoned`, borné, sans rejeu

Propriétaire : `openclaw-plugin-mobile-ui/src/companion/remoteBridge.ts` (reçus `~/.openclaw/remote-bridge/requests/<requestId>.json`). Capture : `fixtures/s24-2026-10-11b/f6/remote-bridge-stuck-receipts.json` (issue #95) : 15 `running` + 1 `indeterminate`, tous `mutationRisk:"unknown"`, 16 instances différentes dont aucun pid n'existe, 4,2 h à 250,9 h, aucun script `processes/cmd-*.sh` lié dans un process vivant.

## Règle
Un reçu `received`, `running` ou `indeterminate` devient `abandoned` quand **toutes** ces conditions sont vraies :
- il appartient à une autre instance que le Companion courant ;
- le pid de cette instance (`INSTANCE_ID = pid-ms-rand`) n'existe plus (`kill(pid, 0)` → `ESRCH`) ; instance illisible ou `EPERM` = vivante ;
- `startedAt` (sinon `receivedAt`) date d'au moins **1 h** (`REMOTE_BRIDGE_ABANDON_AFTER_MS`, au-dessus des 300 s max d'`exec_wait`) ;
- aucun script `remote-bridge/processes/cmd-<ms>-*.sh` à ±10 s de ce départ n'apparaît dans `/proc/*/cmdline` ; `/proc` illisible = pas d'abandon.

Le reçu reste le reçu : `state:"abandoned"`, `completedAt`, `error` lisible et `abandonment {version, at, previousState, reason:"owner_instance_gone", application, ownerInstanceAlive:false, liveCommandEvidence:false, ageMs, afterMs}`. `mutationRisk` est **conservé**. Le `mtime` d'origine est conservé (les lecteurs classent par mtime).

- `application:"not_applied_verified"` seulement si l'état précédent est `received` (le reçu passe à `running` avant le dispatch : `received` prouve que le dispatch n'a pas commencé).
- Sinon `application:"effect_uncertain"` : l'effet passé reste inconnu ; `abandoned` décrit la requête, pas l'effet.

**Sans rejeu** : `abandoned` est terminal. Une resoumission du même `requestId` (ou `taskId`/`stepId`) renvoie ce reçu sans dispatch. `claw_status` projette `state:"abandoned"`, `application`, `mutation_risk`.

## Chemins (existants, aucun timer en boucle)
- Lecture paresseuse : `normalizeStaleReceipt` (relecture, rejeu, `claw_status`). Un reçu d'une autre instance plus jeune que 1 h garde le comportement existant (`indeterminate`).
- Un passage borné (3 s) au démarrage du Companion, 30 s après l'écoute ; son résumé est exposé dans `GET /v1/remote-bridge/health` (`abandonSweep`), route existante.

## Tests
`scripts/test-remote-bridge-abandoned.cjs` (CI) : les 16 reçus réels deviennent `abandoned/effect_uncertain` avec `mutationRisk` conservé ; `received` → `not_applied_verified` ; reçu récent, instance vivante ou script encore vivant conservés ; 50 000 reçus terminés intacts (balayage ~0,6 s) ; lecture paresseuse ; resoumission sans rejeu.

## Retour arrière

# R15 — surfaces connectées, lecture seule

GET `/v1/security/surfaces` : {success,state,receipt:null,items,issues}. Loopback sans contexte navigateur ; Origin/Referer → 403, POST → 405, query inconnue → 400. Aucun endpoint de révocation dans cette version. Toutes les entrées revocable:false.

Clients : liste des clients vus depuis 30 jours dans les reçus existants du Remote Bridge. Le Worker ne fournit pas de liste de configuredClients ; issues contient mcp_config_not_readable. Une surface non vue n'est pas présentée comme configurée. Dernière activité = receivedAt du dernier reçu admissible, jamais une estimation. Les nouveaux reçus MCP conservent l'objet fermé _claw_access issu du profil authentifié, dans leur propriétaire existant ; aucun nouveau registre. Les corps HTTP perdent _claw_access ; seul le pont MCP interne peut attester le profil par une provenance WeakMap en mémoire, non sérialisable. Sur reçus historiques sans cet objet, profile/owner/readOnly:null, issue mcp_profile_unavailable : un nom de méthode ne prouve pas l’identité du client. Les appels context/resolve/status qui ne créent pas de reçu ne changent pas cette date. La page n'est pas une liste exhaustive des autorisations Worker.

Transports WhatsApp et Slack : projection canonique R9, enabled booléen ou null ; lastActivityAt issu de lastDeliveryAt lisible ou null. reason:transport_configuration_read_only. Cache de cette vue en mémoire 15 secondes, single-flight, aucun stockage propriétaire supplémentaire. Attente de lecture bornée à une seconde ; état inconnu si le propriétaire ne répond pas à temps, lecture suivante peut utiliser le résultat reçu. Aucun job ni configuration modifié.

Lecture bornée des reçus : énumération de tout le répertoire admissible et classement par mtime ; au plus 500 contenus lus, 256 Kio par fichier, 8 Mio au total, budget de scan 350 ms ; dépassement déclaré par mcp_receipt_scan_limited, pas de prétention d’exhaustivité. Toute lecture incomplète (budget, plafond de contenus ou octets) rend lastActivityAt:null pour tous les clients MCP projetés, jamais une date issue d’un échantillon. Symlinks de fichiers et parents refusés, fichiers ouverts O_NOFOLLOW / O_NONBLOCK. Reçus corrompus signalés sans leur contenu. Labels fermés, profils fermés, identifiants filtrés. Aucun contenu, commande, numéro, credential ou URL dans la réponse. Les numéros de huit chiffres et les termes sensibles sont exclus des champs libres.

Tests : ingress MCP local conserve le profil dans son reçu ; clients historiques, profil inconnu, expiration 30 jours, transport partagé avec R9, aucun secret/contenu, fichiers propriétaires identiques avant/après lecture, symlink refusé, POST405/Origin403, vingt lectures chaudes sous 1,5 s en moyenne.

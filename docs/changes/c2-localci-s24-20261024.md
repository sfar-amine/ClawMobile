# Chantier 2 : la CI canonique tourne aussi sur le S24

Décision d'Amine du 24/10 (S24 `35b224a6`) : aucune dépendance au PC ; développement, tests et livraison autonomes sur le
S24. Elle remplace, pour ce point, l'ancienne règle « jamais de CI sur le S24 ».

`tools/localci.py` reste le seul propriétaire de la CI. Il remplace son refus fixe sur Termux par un profil `s24` explicite :
- le verrou de déploiement est tenu en exclusif : un seul travail lourd ; si un déploiement ou une campagne QA le tient,
  rien ne démarre ;
- la priorité est basse ;
- chaque étape reçoit un HOME privé, sans les variables d'identifiants et de service de Samantha ;
- la PR est vérifiée par `refs/pull/N/{head,merge}` récupérés par git, car le S24 n'a pas de `gh`.

Toutes les étapes du workflow restent exécutées. Termux sans le profil est refusé avec la commande à utiliser.

`tools/localci-s24.sh` récupère le head exact par l'accès git existant du S24, entre dans le Debian proot avec un environnement
vide et laisse le journal et un reçu (`exit_code`, `log_sha256`, révision du propriétaire) dans `~/.cache/localci-s24/logs/`.
Les étapes qui lisent le dépôt jumeau par `gh api` (référence de branche, contenu à une révision) passent par
`tools/localci_s24_gh.py`, qui répond depuis des miroirs git mis à jour par le lanceur ; tout autre appel `gh` échoue visiblement. Les récupérations
git par URL GitHub d'un dépôt Samantha (`git fetch https://github.com/sfar-amine/…`) sont redirigées vers ces mêmes miroirs
(`url.insteadOf`), l'étape vérifiant toujours la révision obtenue.
`tools/localci_s24_toolchain.sh` installe et vérifie, par les listes SHA-256 des éditeurs, Node 20, 22 et 26.11.1, Python 3.12
(uv) PyYAML, git et file dans ce Debian.

Limites : PRoot n'est pas un bac à sable de sécurité. Le HOME privé et l'environnement vidé évitent les accès
accidentels aux données réelles ; ils n'isolent pas un test hostile. La tête de PR est lue par `refs/pull/N/{head,merge}`,
non par l'API : la base retenue est le premier parent de la référence de fusion calculée par GitHub.

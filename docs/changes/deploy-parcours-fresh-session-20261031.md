# Parcours de déploiement : une session neuve à chaque passage (31/10/2026)

Les parcours de déploiement réutilisaient toujours la même conversation de recette. Après le refus de l'agenda du
30/10, cette conversation gardait l'échec : au déploiement suivant, le cerveau a répondu « l'accès Agenda est toujours
indisponible » sans rappeler l'outil, et le déploiement a été annulé sur l'historique, pas sur le code. Chaque passage
ouvre maintenant sa propre session, et les variantes « est (toujours / momentanément) indisponible » comptent comme
une réponse cassée.

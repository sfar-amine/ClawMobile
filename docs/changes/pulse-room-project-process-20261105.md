# Pièce Pulse : déroulé d'un projet dans la consigne du modèle (05/11/2026)

## Pourquoi
Sur le projet 20933, Sadok a donné son équipe pour un projet qui existait déjà. La pièce a relancé la création du projet et l'équipe affaire est restée vide jusqu'à ce qu'Amine le remarque.

## Ce qui change
La consigne de l'outil de la pièce Pulse dit maintenant :
- l'ordre : projet, phase, commandé, équipe affaire, puis le forecast en dernier ;
- une équipe donnée pour un projet existant s'ajoute tout de suite à son équipe affaire, une affectation par personne, sans attendre le forecast ni recréer le projet ;
- la Matrice profils n'est jamais modifiée (règle générale d'Amine) ;
- le forecast se donne en JH ou en % du commandé du profil, linéaire sur N mois ; le tableau par mois est montré au contact, qui doit le confirmer avant l'écriture.

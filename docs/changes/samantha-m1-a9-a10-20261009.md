## A9 — C3 candidate stimulus corpus
`openclaw-plugin-mobile-ui/scripts/fixtures/samantha-voice-corpus-v1.jsonl` contains metadata for **22** scenarios in **all 19** C3 categories. Each record uses only `id, cat, lang, stimulus, expect, origin`; no real audio, credentials, transcripts, recordings or user content. The mandatory **REQ-1652** case `guard-es-que-noise` expects `reject`. This is a **candidate test design**, not acoustic ground truth or automated full E2E evidence. Languages covered include French, English, Arabic, Tunisian Arabic/Latin and mixed speech; both real and spurious barge-in cases are represented.

## A10 — measurement tooling
`openclaw-plugin-mobile-ui/scripts/voice-m1-analyze.py` reads the two JSONL streams of the versioned C1 schema, correlates solely by `(sid,turn)` on the S24 **CLOCK_BOOTTIME** timebase, and reports internal stage breakdowns (prewarm, token helper, WebSocket, relay of end-of-activity, provider→app first audio, AudioTrack first write→presentation, detection→stop). Negative or incomplete intervals are excluded and counted. No raw payload is copied into output.

**Critical constraint:** actual spoken-sentence end `t23` and barge onset `t40` must come from the external recorder aligned to S24, never from Silero. Thus this tool does **not** report the primary UX metric `t32 - t23` or user-onset barge-in `t41-t40` / `t43-t40`; it reports these as missing external reference. No P95 is published with fewer than 100 samples. With fewer samples use P50/P90/max.

Example (only once app and Companion telemetry are instrumented):
```sh
adb -s 127.0.0.1:5556 logcat -d -s SamanthaVoiceT -v raw > /safe/path/voice-app.jsonl
python3 openclaw-plugin-mobile-ui/scripts/voice-m1-analyze.py /safe/path/voice-app.jsonl ~/.openclaw/telemetry/voice/DATE.jsonl
```
The app/Companion event producers are **not** added or activated by this branch.

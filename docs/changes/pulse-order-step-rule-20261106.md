# Pièce Pulse : le commandé, une étape à part entière entre l'équipe et le forecast (06/11/2026)

## Pourquoi
Règle d'Amine du 06/11 : pour toute création de projet Pulse, l'ordre est le suivant :
1. projet ;
2. phase ;
3. équipe affaire ;
4. commandé, une étape à part entière dont le tableau par profil est accepté par le contact ;
5. forecast.

La consigne de Sol donnait encore « projet, phase, commandé, équipe affaire, puis le forecast ».

## Ce qui change
- La consigne du process projet de la pièce Pulse suit le nouvel ordre.
- L'exécution dans Pulse (ordre d'écriture, reçu de la pièce, « oui » lié au tableau du commandé) est faite côté playbooks dans un lot jumeau.
